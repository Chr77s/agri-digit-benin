Vérifier un autre code

8 caractères imprimés sous le QR code. Pas de 0, O, 1 ni I, pour éviter les confusions. Le code contient 8 lettres ou chiffres. Recopiez-le depuis la carte.

Codes de démonstration : K7M2Q9XA (valide), H3RT8WPZ (en attente), Z9XB4MNC (non valide). Tout autre code est inconnu.

En cas de doute

  1. Comparez le nom affiché avec la pièce d'identité de la personne.
  2. Si la carte est non valide ou inconnue, ne l'acceptez pas comme preuve.
  3. Signalez-le à l'agent ATDA de la commune : il peut vérifier la fiche complète.
